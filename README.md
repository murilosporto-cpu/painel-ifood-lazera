# Portal Executivo Domino's Pizza - Empresa Lazera (São Luís - MA)

Portal exclusivo para análise de performance no iFood das operações da franqueada **Áurea** (**Empresa Lazera**).

## Praças e Unidades Monitoradas (São Luís - MA):
- **DOMINOS SAO LUIS (COHAMA)**
  - Domino's Pizza - Cohama
  - Domino's Sanduíches - Cohama
- **DOMINOS SAO LUIS 2 (RENASCENCA)**
  - Domino's Pizza - Renascença
  - Domino's Sanduíches - Renascença

## Painéis Integrados (3 em 1):
1. `index.html`: Avaliações, NPS, notas, tags e feedbacks de clientes no iFood.
2. `cancelamentos.html`: Cancelamentos de pedidos, perdas financeiras (R$), motivos e contestações.
3. `super.html`: Acompanhamento oficial do programa Super Restaurantes iFood, projeção de níveis, funil e metas.
